📋 Brand Guidelines

  • Logo: Gunakan logo utama pada header, footer, dan branding materials. Minimal size: 80px × 80px untuk visibility optimal.
  • Warna Primer (#F97316): Digunakan untuk CTA buttons, highlights, dan important elements. Menciptakan kesan energik dan modern.
  • Icons: Semua icons memiliki stroke-width konsisten 2px dan rounded corners. Scalable untuk berbagai ukuran (16px - 64px).
  • Typography: Gunakan font modern seperti Inter, Poppins, atau Segoe UI untuk konsistensi di semua platform.
  • Spacing: Ikuti prinsip 8px grid system untuk alignment dan consistent spacing.
  • Dark Mode: Gunakan opacity dan adjust warna untuk dark mode compatibility.
  • Accessibility: Semua icons dapat di-customize dengan 'stroke' dan 'fill' untuk contrast ratio yang baik.
